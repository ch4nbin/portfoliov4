# Personal Website

Build a very simple, barebones personal website for Chanbin Park.

This is a personal homepage.

## Product Goal

Create a minimal personal website that feels clean, technical, and understated.

The site should be right-aligned, mostly plain text, and use default Arial styling. It should feel like something a very strong engineer/designer would make because it is simple and intentional, not because it is flashy.

## Design Direction

Use:

- Arial font
- Black text
- White background
- Right-aligned layout
- Plain links
- Lots of whitespace
- Minimal CSS

Avoid:

- gradients
- glassmorphism
- cards
- shadows
- icons
- emojis
- animations
- colorful UI
- corporate portfolio styling
- AI-generated marketing language

## Layout

Everything should be right-aligned.

At the top:

```text
chanbin park

Below that, include these sections:

about

Keep section labels lowercase.

Content Style

Write plainly and concisely.

Do not make the site sound like a startup landing page. Do not oversell. Do not use buzzwords.

The tone should be personal, simple, and direct.

Frontend Instructions

Use the frontend-design skill when making UI/design decisions.

Even though the design is intentionally barebones, the implementation should still be polished:

clean spacing
consistent alignment
readable hierarchy
responsive layout
no unnecessary dependencies

Preferred stack:

React + Vite
TypeScript if already configured
Plain CSS
No component library
No Tailwind unless already installed
Claude Skills Folder

If this repo has a .claude/skills folder, check it before making large implementation decisions.

Use any relevant local skill instructions, especially for:

frontend design
project conventions
styling conventions
deployment instructions

Do not ignore repo-specific Claude instructions if they exist.

Implementation Rules

Keep the code simple.

Prefer:

one main page
minimal components
straightforward CSS
semantic HTML
accessible links
mobile-friendly layout

Do not add:

routing unless needed
dashboards
complex animations
design systems
fake content-heavy sections
unnecessary libraries
